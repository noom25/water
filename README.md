# ประปา อปท

ระบบจัดเก็บค่าน้ำประปาสำหรับองค์กรปกครองส่วนท้องถิ่น (อบต./เทศบาล) ที่บริหารกิจการประปาเอง

**แจกฟรี** สำหรับหน่วยงานที่ต้องการใช้งาน

## ทำอะไรได้

- จดเลขมาตร คำนวณค่าน้ำ (ราคาเดียว / ขั้นบันไดสะสม / ขั้นบันไดทั้งก้อน) ค่าน้ำขั้นต่ำ ค่ารักษามาตร
- ออกใบแจ้งค่าน้ำ 3 แบบ — ใบเสร็จ+ใบแจ้งหนี้ 2 ราย/แผ่น · แบบย่อ 2 ราย/แผ่น · ใบแจ้งค่าน้ำ 6 ราย/แผ่น
- รับชำระ ออกใบเสร็จ (ต้นฉบับ/สำเนา) คิดค่าปรับอัตโนมัติ ยกเลิกใบเสร็จพร้อมบันทึกเหตุผล
- ติดตามหนี้ค้างชำระ รายงานประจำเดือน/ปีงบประมาณ งบรายรับ-รายจ่าย
- **ส่งออกไฟล์นำเข้าลูกหนี้รายได้ (AR3) ของ e-LAAS** โดยใช้เทมเพลตจริงเป็นฐาน
- **เก็บพิกัดมาตรน้ำ ส่งออก GeoJSON/CSV** สำหรับงานแผนที่ภาษีและ QGIS
- เตือนเลขมาตรผิดปกติ ตรวจความต่อเนื่องของเลขมาตร สำรองอัตโนมัติ 14 ชุด ประวัติการแก้ไขข้อมูล

## วิธีใช้

เปิดลิงก์ระบบแล้วกด **"เพิ่มไปยังหน้าจอโฮม"** (iPhone/iPad) หรือ **"ติดตั้ง"** (Android/คอมพิวเตอร์)
หลังติดตั้งแล้วใช้งานออฟไลน์ได้ ไม่ต้องต่ออินเทอร์เน็ต

คู่มือการใช้งานฉบับเต็มอยู่ในเมนู **📘 คู่มือ** ในตัวระบบ มี 15 หัวข้อ

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บอยู่ในเบราว์เซอร์ของเครื่องที่ใช้งาน **ไม่มีการส่งข้อมูลออกไปที่ใดทั้งสิ้น**
ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่มีการเก็บสถิติ

ดังนั้น **ต้องสำรองข้อมูลเป็นไฟล์ .json อย่างน้อยสัปดาห์ละครั้ง** และเก็บไว้นอกเครื่อง
ระบบจะเตือนเองบนหน้าแดชบอร์ดถ้าไม่ได้สำรองเกิน 7 วัน

## สำหรับผู้ดูแล repo นี้

ห้าม commit ไฟล์สำรอง `.json`, ทะเบียน `.csv`, `.xlsx` หรือ `.geojson` ที่มีข้อมูลจริง
เพราะมีชื่อ–ที่อยู่–เบอร์โทรของประชาชน — `.gitignore` กันไว้แล้ว แต่ให้ตรวจก่อน push ทุกครั้ง
https://noom25.github.io/water/

เวลาอัปเดตเวอร์ชันใหม่ ต้องแก้ `VERSION` ใน `sw.js` ด้วย ไม่งั้นเครื่องที่ติดตั้งไปแล้วจะยังใช้ไฟล์เก่า
